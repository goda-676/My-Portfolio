# Personal Portfolio Website

A simple, responsive personal portfolio page built with **HTML** and **CSS** as a front-end assignment.

## About the Project

This project presents who I am, what I can do, and how to reach me in one clean page. It includes:

- **Header** with my name, job title, and navigation buttons that scroll to each section.
- **About Me** with my photo, a short introduction, and a link to my GitHub.
- **Skills** displayed as cards, each with a short description.
- **Experience** with the courses I took and the work I do (NTI / Huawei, Route Academy, and freelancing).
- **Contact Me** with links to my Email, LinkedIn, and GitHub.
- **Footer** with copyright information.

## Technologies Used

- HTML5 (semantic structure, links, images)
- CSS3 (Flexbox, custom colors, hover effects, media queries for small screens)

## Project Structure

```
├── index.html   # Page structure and content
├── style.css    # All the styling
└── images       # Profile photo and experience logos
```

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any browser (or use the Live Server extension in VS Code).
